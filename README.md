
# 🚀 SQL: From Beginner to Advanced 📊

Welcome to my comprehensive SQL Master Repository! This is a structured journey through the world of data, covering everything from basic syntax to complex data engineering architectures. 

Whether you are looking for study notes, hands-on practice queries, or end-to-end analytics projects, you will find them organized here.

---

## 🗺️ Learning Roadmap & Repository Structure

This repository is designed to be followed sequentially, moving from theory to implementation and finally to professional application.

### 📂 [1. Topics](./Topics)
Detailed explanations of SQL concepts. This folder covers:
* **Beginner:** SELECT, WHERE, Joins, Group By, Aliases.
* **Intermediate:** Subqueries, Set Operators, Aggregations, Case Statements.
* **Advanced:** Window Functions (Rank, Lead/Lag), CTEs, Stored Procedures, and Optimization.

### 📝 [2. Notes](./Notes)
My personal "Cheat Sheets" and conceptual deep-dives. Perfect for quick revision of complex logic like `RANK()` vs `DENSE_RANK()` or the logical order of SQL execution.

### 💻 [3. Queries](./Queries)
The practice ground. Contains:
* Daily practice questions.
* Real-world scenario-based query challenges.
* Solutions to complex data manipulation problems.

### 🏗️ [4. Projects](./Projects)
The application of everything learned. Featured projects include:
* **Data Warehouse Project:** Medallion Architecture implementation.
* **Advanced EDA:** Deep statistical data discovery.
* **Pizza Sales:** Business Intelligence & KPI reporting.
